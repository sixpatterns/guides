# Tech stack

We use specific tools for specific jobs:

- Backend: Ruby on Rails
- Database: PostgreSQL
- API: GraphQL
- Frontend (Admin/App): React + Vite + TypeScript
- Frontend (SEO needed): Next.js + TypeScript
- Mobile: React Native + TypeScript
- Styling: TailwindCSS
